## 产品概述

修改贪吃蛇游戏的陷阱生成机制和蛇的眼睛视觉效果

## 核心功能

- 提升陷阱生成概率从50%到75%
- 限制陷阱数量不超过蛇身长度的三分之一
- 将蛇的眼睛颜色改为白色

## 技术栈

- 前端框架：React + TypeScript
- 样式方案：Tailwind CSS
- 绘图方式：HTML5 Canvas

## 技术架构

### 修改范围

本次修改仅涉及两个文件的局部逻辑更新：

- **App.tsx**: 陷阱生成概率和数量计算逻辑（第213-221行）
- **GameCanvas.tsx**: 蛇眼睛颜色（第168行）

### 修改内容说明

**1. App.tsx - 陷阱生成逻辑修改**
将第214行的概率判断从 `Math.random() < 0.5` 改为 `Math.random() < 0.75`
将第216行的陷阱数量计算改为 `Math.floor(snake.body.length / 3) - traps.length`，确保陷阱总数不超过蛇身长度的三分之一

**2. GameCanvas.tsx - 眼睛颜色修改**
将第168行的眼睛颜色从 `'#1a1a2e'` 改为 `'#ffffff'`

## 实现细节

### 核心代码结构

**陷阱生成逻辑（修改后）**：

```typescript
// 每增加3节，有75%概率批量生成陷阱
if (lengthIncrement > 0 && lengthIncrement % 3 === 0 && Math.random() < 0.75) {
  // 陷阱数量：不超过蛇身长度的三分之一，减去已有陷阱数量
  const maxTraps = Math.floor(snake.body.length / 3);
  const trapCount = Math.max(1, maxTraps - traps.length);
  if (trapCount > 0) {
    batchSpawnTraps(trapCount, allOccupied);
    updateInitialLength(snake.body.length);
  }
}
```

**眼睛绘制（修改后）**：

```typescript
// 绘制眼睛
ctx.fillStyle = '#ffffff'; // 从 '#1a1a2e' 改为白色
```
